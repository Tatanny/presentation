# Татьяна Шерстнева — презентация для собеседования

Статический сайт: главная страница, кейсы Flowly и центра уведомлений.

## Публикация

1. Создать отдельный публичный репозиторий `presentation` в аккаунте Tatanny.
2. Загрузить содержимое этой папки в корень репозитория, включая `.nojekyll`.
3. В Settings → Pages выбрать Deploy from a branch → main → /(root).
4. После успешной публикации адрес сайта: https://tatanny.github.io/presentation/.

Английское портфолио в tatanny.github.io остаётся отдельным сайтом.
Сборка и зависимости не нужны. Для обновления заменять файлы с сохранением путей.
Google Fonts загружается из интернета. Изображения и страницы кейсов находятся локально.
